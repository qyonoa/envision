기초 모델링

3D 모델링의 기초를 배우며 창작의 재미를 느끼고,
빠르게 결과물을 완성해보는 과정
  • 대상 : 3D 모델링을 처음 접하시는 분
  • 인원 : 그룹 (4명)
  • 기간 : 기간 : 8주 (주 1회, 2시간)
01

실무 파이프라인 익히기

단순 툴 학습을 넘어 실무 인터페이스와 단축키 셋팅을 전수합니다. 간단한 프롭 제작을 통해 전체적인 작업 흐름을 파악합니다.

02

데이터 중심 형태 제작

비례와 구조 원리를 적용하여 기본기를 다집니다. 레퍼런스 수집부터 로우폴리곤 최적화까지 TA의 안목으로 피드백합니다.

03

하이엔드 렌더링 출력

기본 조명과 카메라 앵글 설정을 통해 결과물의 가치를 높입니다. 완성된 결과물을 포트폴리오로 구성하는 전략을 배웁니다.

수강생 맞춤 VOD 제공

포트폴리오의 성격과 작업 진행 상황에 맞춰, 작품 완성에 실질적인 도움이 될 만한 양질의 VOD를 통해 성장을 적극적으로 서포트합니다

무제한 실시간 피드백

작업 중 막히는 부분, 엔진 환경에서의 셰이더 오류나 최적화 이슈 등 기술적인 문제에 대해 실시간으로 밀착 피드백을 진행하여 작업 흐름이 끊기지 않도록 돕습니다.
